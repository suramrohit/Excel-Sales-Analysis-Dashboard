# Excel Sales Analysis Dashboard

An interactive **Sales Analysis Dashboard** built using Microsoft Excel to analyze sales performance, customer trends, product performance, and category-wise sales.

## 📊 Project Objective

The objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that helps identify key sales trends and business insights.

## 🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Excel Formulas
* Data Analysis & Visualization

## 📁 Dataset

The dataset contains sales transaction information including:

* Order ID
* Customer
* Gender
* City
* Product
* Category
* Quantity
* Price
* Sales
* Profit
* Date
* Salesperson

## 📈 Dashboard Features

* **Total Sales** – Overall sales generated
* **Total Orders** – Number of orders
* **Total Quantity** – Total units sold
* **Total Customers** – Customer count
* **Monthly Sales Analysis** – Sales performance over time
* **Sales by Category** – Category-wise sales comparison
* **Top 5 Products by Sales** – Best-performing products
* **Top 5 Customers by Sales** – Highest-value customers
* **Interactive Slicers** – Filter and analyze dashboard data dynamically

## 🔍 Key Insights

The dashboard helps identify:

* Overall sales performance
* Monthly sales trends
* Best-performing products
* Highest-value customers
* Category-wise contribution to total sales
* Sales performance across different filters

## 🎯 Project Outcome

This project demonstrates practical skills in **Excel data analysis, dashboard development, PivotTables, PivotCharts, and interactive data visualization**.

It provides a simple and effective way to convert raw sales data into meaningful business insights.
